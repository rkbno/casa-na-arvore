# Casa na Árvore — site estático

```
index.html            home
sobre.html            projetista (foto no topo)
casa-tempo.html
conceitos.html
capela.html
contato.html          formulário (abre o e-mail preenchido)
download-imagens.sh   baixa as imagens do site original
src/
  css/style.css       estilos (cores e fontes em :root)
  js/components.js    cabeçalho e rodapé compartilhados
  js/main.js          menu mobile, carrossel, lightbox, formulário
  img/                imagens (projetista.jpg já incluída)
```

1. Rode `bash download-imagens.sh` para baixar as imagens do site original.
2. Abra `index.html` no navegador (ou publique a pasta no Netlify/Vercel).
